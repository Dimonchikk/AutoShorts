Умови використання

Оновлено 21.11.2026

AutoShorts поширюється безкоштовно, «як є», без будь-яких гарантій. Використовуючи програму, ви погоджуєтеся з цими умовами.

Ваш контент

Ви відповідаєте за те, щоб мати права на відео, які нарізаєте й публікуєте, і за дотримання Умов YouTube та правил спільноти.

YouTube API

Програма використовує YouTube API Services. Користуючись функціями публікації, ви погоджуєтеся з Умовами використання YouTube.

Відповідальність

Розробник не несе відповідальності за втрату даних, блокування каналів чи інші наслідки використання програми.
