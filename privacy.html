Політика конфіденційності

Оновлено 21.11.2026

AutoShorts — безкоштовна програма для Windows, яка працює на вашому комп’ютері. У розробника немає серверів, і програма не передає розробнику жодних ваших даних.

Які дані використовуються

  • Доступ до YouTube. Коли ви підключаєте канал, Google видає програмі токен доступу. Він зберігається лише на вашому комп’ютері, зашифрований засобами Windows (DPAPI) для вашого облікового запису.
  • Що програма робить через YouTube API: завантажує кліпи й обкладинки, які ви самі вибрали для публікації, читає назву вашого каналу, список ваших відео й статистику переглядів — щоб порахувати найкращий час публікації та показати звіт.
  • Відео й налаштування (кліпи, шаблони, журнал) зберігаються в папках на вашому комп’ютері.

Що програма не робить

  • Не продає й не передає дані третім особам.
  • Не збирає аналітику й не надсилає звіти розробнику.
  • Не публікує нічого без вашої дії (або ввімкненого вами автопублікування).

Сервіси Google

Використання даних, отриманих через Google API, відповідає Google API Services User Data Policy, зокрема вимогам Limited Use. Програма використовує YouTube API Services; див. також Умови YouTube і Політику конфіденційності Google.

Як відкликати доступ і видалити дані

Видаліть канал у програмі («Канали» → «Видалити») і відкличте доступ на сторінці myaccount.google.com/permissions. Щоб видалити всі дані програми, видаліть AutoShorts і папку %LocalAppData%\AutoShorts.
