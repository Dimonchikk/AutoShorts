# Шрифти для субтитрів AutoShorts

Шрифти з підтримкою кирилиці (зокрема і, ї, є, ґ). Програма завантажує з цієї папки лише той шрифт,
який вибрано для субтитрів, тому exe лишається маленьким.

(повний текст ліцензії вбудовано в кожен файл, поле «License»).
